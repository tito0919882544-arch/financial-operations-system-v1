# نظام العمليات المالية v1.0 — محطة دلقو

نظام مالي رقابي داخلي يعمل محليًا عبر Flask + SQLite، مخصص لإدارة الإيرادات، التوريدات، طلبات التصديق، النثرية، المستحقات، وسجل التدقيق.

## المعتمد في هذه النسخة

- اعتماد التصميم الجديد: قائمة جانبية داكنة، بطاقات مالية كبيرة، خطوط عربية أوضح، حالات ملوّنة، وتنبيهات رقابية.
- الإيراد يعتمد من المدير.
- التوريد يعتمد من المدير.
- طلب التصديق يعتمد من المدير.
- كل عملية تبدأ بحالة: قيد المراجعة.
- المدير يمكنه: اعتماد / إرجاع للتصحيح / رفض.
- بعد الاعتماد تصبح العملية مقفلة، ولا يتم تعديلها إلا بإجراء تصحيحي مسجل.
- سجل حركة كامل لكل عملية: المستخدم، الوقت، IP، الحالة القديمة والجديدة، والملاحظة.
- أرقام تلقائية موحدة: DLG-REV-0001 / DLG-DEP-0001 / DLG-APP-0001 / DLG-DUE-0001.
- نماذج طباعة رسمية من داخل النظام.
- تنبيهات في لوحة التحكم.
- لا يوجد زر نسخ احتياطي يدوي داخل الواجهة حسب الاعتماد الحالي.

## التشغيل على ويندوز

1. فك ضغط الملف.
2. افتح المجلد.
3. شغّل الملف:

```bat
start_system.bat
```

4. افتح المتصفح على:

```text
http://127.0.0.1:5000
```

ولو أردت الدخول من جهاز آخر داخل الشبكة:

```text
http://IP-ADDRESS:5000
```

مثال:

```text
http://192.168.210.100:5000
```

## ملاحظة مهمة عن IP

داخل `config.py` يوجد الخيار:

```python
ENFORCE_IP_RESTRICTIONS = False
```

تركته مغلقًا أثناء التجربة حتى لا يمنعك اختلاف الجهاز أو الشبكة من الدخول. عند التشغيل الرسمي يمكن تفعيله عبر متغير البيئة أو تعديل الملف إلى True، ثم ربط المستخدم بعنوان IP محدد.
